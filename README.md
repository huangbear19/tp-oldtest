# EMTP 考古題練習

純靜態 GitHub Pages app。發佈時需要上傳：

- `index.html`
- `styles.css`
- `app.js`
- `.nojekyll`
- `data/questions.js`

不需要上傳：

- `scripts/`
- `.DS_Store`

## GitHub Pages 設定

可以放在任一已啟用 GitHub Pages 的 repo：

- User site：`<username>.github.io` repo 的根目錄
- Project site：任一 repo 的根目錄，或 `docs/` 目錄

若使用 project site，網址通常是：

`https://<username>.github.io/<repo-name>/`
